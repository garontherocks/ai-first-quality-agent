# Glossary

- **Agent:** software that uses a model to choose and sequence actions toward a goal.
- **Workflow:** a predefined sequence; unlike an agent, its path does not require model-directed decisions.
- **Tool:** a bounded capability an agent may invoke with validated arguments.
- **MCP:** Model Context Protocol, a standard interface for exposing context and tools to AI clients.
- **Hook:** code executed at a lifecycle boundary, such as before a tool call or after a model response.
- **Provider:** an adapter for a model service or deterministic substitute.
- **Evaluation:** a repeatable measurement of AI-system behavior.
- **Human-in-the-loop:** an explicit approval or review boundary before consequential action.
- **Structured output:** model output constrained to a machine-validated schema.
